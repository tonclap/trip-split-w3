## Почему чужих данных здесь нет

`src/` в `.gitignore`: набор Максима — его работа, а его `facts.md` и `README.md`
содержат эталон. Перекладывать чужие ответы в свой публичный репозиторий незачем.

```bash
git clone https://github.com/baramba/trip-settle-tbilisi src   # коммит 7fa80cb
```

## Как повторить

```bash
python adapt.py      # наш split.py на его данных: балансы, план, спорное
python corrupt.py    # порча входа против проверок — 0 из 7
```

`adapt.py` импортирует `../../split.py` **как есть** и подменяет его константы
снаружи; ни одной строки в нём и в `verify.py` не изменено. Копий этих файлов
здесь нет намеренно — копия разошлась бы с оригиналом.

`verify.py` на этом наборе не запускается вовсе (`FileNotFoundError: data/chat.md`):
он жёстко ждёт наш формат — по файлу на чек в `data/receipts/`.
