# Схема входа: реестр поездки в JSON

`python split.py --data <файл.json>` считает балансы и план переводов по чужому
набору. До 30.09.2026 входа не было: реестр был константами в теле `split.py`, и
прогон на чужих данных приходилось делать переходником снаружи — это была первая
находка обмена наборами (этап 2 недели 1).

Схема — надмножество трёх наборов, на которых она проверена: своего (один курс,
передачи денег между участниками) и двух чужих (курсы по датам, возвраты от
продавца).

## Поля

| Поле | Обяз. | Что |
|---|---|---|
| `people` | да | участники, списком; порядок задаёт, кому достанется остаток копеек |
| `receipts` | да | чеки, список объектов (ниже) |
| `base_currency` | нет | валюта расчёта, по умолчанию `RUB` |
| `rates` | нет | один курс на валюту: `{"GEL": 34.20}` |
| `rates_by_date` | нет | курс на дату: `{"BRL": {"2026-09-22": 16.3064}}` |
| `refunds` | нет | возвраты от продавца по чеку |
| `moves` | нет | передачи денег между участниками (заём, «в счёт долга») |
| `disputed` | нет | спорное: печатается, в расчёт не входит |
| `trip`, `notes` | нет | описание набора и примечания к нему |

Курс нужен для любой валюты, кроме `RUB`: суммы приводятся к рублям на дате
строки (для возврата — на дате возврата), и дальше расчёт идёт в рублях.

### `receipts[]`

```json
{
  "id": "R02", "date": "2026-09-22", "payer": "Костя",
  "amount": 240, "currency": "BRL",
  "for": ["Лена", "Костя", "Нина", "Артём", "Света", "Паша"],
  "what": "такси из аэропорта, две машины",
  "sources": ["R02", "M05", "M06", "M07"],
  "why": "M06 Костя берёт две машины «потом разделим»; чек R02 на 240 R$"
}
```

`sources` — чек и сообщения, из которых следуют плательщик и состав дележа.
Строка без непустого источника отвергается (`check_structure`), потому что состав
дележа без ссылки — догадка. `why` не проверяется машиной и нужен человеку,
который будет разбирать реестр.

### `refunds[]`

```json
{
  "id": "V01", "date": "2026-09-24", "to": "Костя",
  "amount": 480, "currency": "BRL", "receipt": "R07",
  "what": "лодку отменили из-за шторма",
  "sources": ["V01", "M24", "M28"]
}
```

Возврат — это **уменьшение самого расхода**, а не передача денег: он становится
минус-строкой реестра с тем же составом дележа, что у чека `receipt`, и
пересчитывается по курсу на `date` возврата. Возврат больше исходного чека или
записанный плюсом отвергается.

### `moves[]`

```json
{
  "from": "Тимур", "to": "Макс", "amount": 2000, "currency": "RUB",
  "date": "2026-09-13", "kind": "в счёт долга",
  "note": "часть долга, остальное в Москве", "sources": ["M30", "M32", "M33"]
}
```

Кто отдал — у того долг уменьшился (баланс +), кто получил — у того уменьшилось
требование (баланс −).

### `disputed[]`

```json
{
  "id": "D3", "sources": ["M29", "M30", "R11"], "who": "Артём",
  "what": "чек на 420 против «вышло 460»",
  "action": "сумма по чеку; расхождение в «спорное», в расчёт не входит"
}
```

## Чего вход не даёт

Эталона у чужого набора нет, поэтому сверка `check_against_expected()` не
запускается, и остаются только структурные проверки: они ловят испорченный
источник, пустой или посторонний состав дележа, перевёрнутый знак возврата и
пропавшую строку — но **не** изменённую сумму, подменённого плательщика или
поехавший курс. Прогон это говорит прямым текстом; проверить границу:

```bash
python split.py --data <файл.json> --corrupt
```

`verify.py` (сверка реестра с файлами чеков и чатом, доказательство минимальности
плана) на чужой вход пока не переведён — он привязан к формату `data/` своего
набора. Это известный долг.
